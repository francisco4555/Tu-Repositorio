# JFR — Hero corregido

Esta carpeta contiene únicamente la sección inicial (hero) y está lista para GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `script.js`
- `assets/perfil.jpg`

## Importante sobre la foto
`assets/perfil.jpg` ya existe para que la página no muestre un cuadro vacío.
Es una imagen temporal de reemplazo.

Para usar tu retrato real:
1. Elimina `assets/perfil.jpg`.
2. Sube tu fotografía.
3. Ponle exactamente el nombre `perfil.jpg`.
4. Déjala dentro de la carpeta `assets`.

La ruta debe quedar:
`assets/perfil.jpg`

## Animaciones incluidas
- Movimiento continuo de la línea azul punteada.
- Entrada animada del título y textos.
- Entrada del retrato.
- Etiquetas flotantes.
- Movimiento sutil del retrato con el cursor en escritorio.
- Hover animado del botón naranja.
- Animación del aro punteado.

## Publicar en GitHub Pages
Sube el contenido de esta carpeta a la raíz del repositorio.

Estructura:

jfr-hero-github-corregido/
├── index.html
├── styles.css
├── script.js
└── assets/
    └── perfil.jpg

Después ve a:
Settings → Pages → Deploy from a branch → main → /(root) → Save

No necesitas cambiar rutas: todos los archivos usan rutas relativas compatibles con GitHub Pages.
