# JFR Hero
Sección inicial independiente, lista para GitHub Pages.

## Retrato
Agrega tu foto como `assets/perfil.jpg`. La página la convierte visualmente a blanco y negro.

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a la raíz de un repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique la URL.

`assets/referencia.png` es únicamente la captura visual de referencia y puedes eliminarla después.
